curl -H "X-Api-Key: me_live_your_key_here" https://your-api.com/api/v1/rooms

React SDK
React SDK

@meeting-engine/react provides hooks and components for building meeting UIs.

Installation
npm install @meeting-engine/react
Copy

Requires React 18+ as a peer dependency.

useMeetingSession

The main hook that manages the entire meeting lifecycle.

import { useMeetingSession } from '@meeting-engine/react'

const meeting = useMeetingSession({
  serverUrl: 'wss://your-server.com',   // From token API response
  token: 'eyJ...',                       // JWT from /api/v1/tokens
  roomName: 'my-room',
  userName: 'Alice',
  participantIdentity: 'user-1',
})
Copy
Returned State
Property	Type	Description
phase	'preview' | 'connecting' | 'live' | 'reconnecting' | 'error'	Current connection state
participants	MeetingParticipant[]	All participants in the room
audioOn	boolean	Local microphone state
videoOn	boolean	Local camera state
sharingOn	boolean	Screen sharing state
chatMessages	ChatMessage[]	Chat message history
participantCount	number	Total participant count
elapsedLabel	string	Meeting duration (HH:MM:SS)
Actions
Method	Description
connect()	Join the meeting room
disconnect()	Leave the meeting
toggleMic()	Toggle microphone on/off
toggleCam()	Toggle camera on/off
toggleShare()	Toggle screen sharing
toggleNoiseCancellation()	Toggle Krisp noise cancellation
sendChatMessage(text)	Send a chat message
selectCamera(deviceId)	Switch camera device
selectMicrophone(deviceId)	Switch microphone device
setVirtualBackground(option)	Set blur or image background
